## ✨ Возможности

- **🔥 Вызов глобальной горячей клавишей** — слой заметок показывается и скрывается сочетанием `Ctrl+Alt+Space` (по умолчанию) и перекрывает любые приложения, даже в полноэкранном режиме. Поддерживаются все модификаторы — `Ctrl` / `Alt` / `Shift` / `Cmd⌘` (Win); сочетание можно перезаписать в настройках.
- **🪟 Настоящее матовое стекло** — Windows использует системный эффект Acrylic; на macOS доступны три переключаемых фоновых эффекта: полная прозрачность, «жидкое стекло» (`NSGlassEffectView`, macOS 26+, автоматический откат на старых версиях) и NS-матовое стекло.
- **📝 Блочный WYSIWYG-редактор Markdown** — содержимое делится на блоки по пустым строкам. Редактируемый блок показывает исходный Markdown с живой подсветкой синтаксиса, остальные мгновенно отображаются как форматированный текст. Поддерживаются блоки кода, нумерованные / маркированные списки, чек-листы, цитаты и другое; чекбоксы переключаются кликом.
- **🗒 Свободное расположение стикеров** — заметки можно перетаскивать и свободно масштабировать; новые заметки выстраиваются каскадом, а при восстановлении координаты возвращаются в пределы экрана.
- **🌍 8 языков интерфейса** — 简体中文 (по умолчанию), English, Español, 日本語, 한국어, Русский, Français, Deutsch.
- **🔒 Полностью локальное хранение** — все данные заметок лежат в localStorage на вашем компьютере. Без облачной синхронизации, телеметрии и сетевых запросов.
- **⚙️ Ещё детали** — экспорт в файл одним кликом, опциональный автозапуск, защита от второго экземпляра (повторный запуск пробуждает существующее окно).

## ⌨️ Горячие клавиши

| Действие | По умолчанию | Примечание |
| --- | --- | --- |
| Показать / скрыть слой заметок | `Ctrl+Alt+Space` | Системная глобальная клавиша, настраивается |
| Новая заметка | `Ctrl+N` | Внутренняя клавиша приложения, настраивается |
| При редактировании: разбить на новый блок | `Enter` | Markdown редактируется по блокам; пустая строка разделяет блоки |
| При редактировании: перенос строки внутри блока | `Shift+Enter` | Отображается как мягкий перенос |
| В списке: увеличить / уменьшить отступ | `Tab` / `Shift+Tab` | Для многоуровневых списков |

## 📦 Установка

Скачайте установщик для своей платформы со страницы **Releases** этого репозитория:

- **Windows**: установщик / MSIX
- **macOS**: образ dmg

> Фоновые эффекты в версии для macOS опираются на приватные API (`macOSPrivateApi`). Уровень «жидкое стекло» требует macOS 26 или новее; на старых системах автоматически используется NS-матовое стекло.

## 🛠 Сборка из исходников

Требуются: [Node.js](https://nodejs.org/) ≥ 18 и стабильный инструментарий [Rust](https://www.rust-lang.org/).

```bash
cd glass-notes
npm install

npm run tauri dev     # разработка с горячей перезагрузкой
npm run tauri build   # сборка релизных установщиков
```

## 📁 Структура проекта

```
glass-notes/
├── package.json         # Зависимости и скрипты фронтенда; npm-команды выполняются здесь
├── vite.config.mjs
├── src/                 # Исходники фронтенда (чистый JS, без фреймворков)
│   ├── main.js          # Панель настроек, переключение языка, запись сочетаний клавиш
│   ├── notefunc.js      # CRUD заметок, перетаскивание и масштабирование, экспорт, хранение
│   ├── markdown.js      # Блочный WYSIWYG-редактор Markdown
│   ├── language.js      # Все строки интерфейса на 8 языках
│   └── marked.esm.js    # Встроенная копия marked
└── src-tauri/           # Rust-бэкенд (точка входа — src/main.rs)
    └── src/main.rs      # Регистрация глобальных клавиш, окно и стеклянные эффекты, адаптация под платформы
```

## 🔒 Приватность

Glass Notes не собирает никаких пользовательских данных. Заметки хранятся только в браузерном хранилище (localStorage) на вашем компьютере, а экспорт всегда инициируется вами. Подробности — в [privacy.md](privacy.md).
